The **Pay API** provides digital wallets, ledger transactions, checkout sessions, and rail-based payout and collection endpoints. Public paths use `payouts`, `collections`, and `checkout-sessions`.

## Base path

`/api/v1/payments`

## Authorization

Developer JWT + API key on every request. See [Authorization](/getting-started/authorization).

## Key route groups

| Group | Path prefix | Purpose |
| --- | --- | --- |
| Checkout | `/checkout-sessions` | Hosted checkout (`card`, `mobile_money`) |
| Payouts | `/payouts` | Bank beneficiaries and transfers |
| Collections | `/collections` | Mobile money charges and verify |
| Channels | `/channels` | Org collection channel policy |
| Capabilities | `/capabilities/org` | Supported payout rails |

## Typical integration flow

1. Provision or fetch wallet accounts for your organization
2. Create a checkout session or call payout/collection APIs by rail
3. Poll checkout status or transaction status
