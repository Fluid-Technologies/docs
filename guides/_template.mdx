# Guide title

One-sentence overview of what the integrator will accomplish.

<Note>
Partner integrations: include `X-Workspace-Id` and `X-Acting-Company-Id` on product API calls when scoping to a merchant.
</Note>

## Prerequisites

- Developer API key and machine JWT — [Authorization](/getting-started/authorization)
- Permission: `module:resource:action`
- Data that must exist first

## Steps

<Steps>

<Step title="First API call">

```bash
curl -sS "$FLUIDE_BASE_URL/api/v1/..." \
  -H "Authorization: Bearer $FLUIDE_ACCESS_TOKEN" \
  -H "X-Fluide-Api-Key: $FLUIDE_API_KEY" \
  -H "X-Fluide-Client-Id: fluide-developer"
```

</Step>

</Steps>
