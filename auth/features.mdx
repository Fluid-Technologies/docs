# Auth features

| Capability | Supported | Notes |
| --- | --- | --- |
| Email + password | Yes | `POST /api/v1/auth/sign-in`, `sign-up` |
| Email OTP | Yes | Verify and passwordless sign-in |
| Google / Apple / Microsoft | Yes | When enabled for your environment |
| Enterprise OIDC SSO | Yes | `POST /api/v1/auth/sso/authorize` |
| Magic link sign-in | No | Password reset uses a reset link, not a sign-in link |
| TOTP / 2FA on sign-in | No | |
| Phone / WhatsApp OTP | No | |

Organizations are managed at `/api/v1/organizations/*`.

See [Enterprise SSO](/auth/sso).
